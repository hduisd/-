# PROJECT_CONTEXT — Minecraft-мод «Віктор»

## Технічні дані
- Назва: Viktor / «Віктор», mod id: `viktor`, пакет: `com.viktor`
- Minecraft Java 1.21.1, NeoForge 21.1.x (у `gradle.properties`: `neo_version=21.1.172`)
- Java 21, збірка: ModDevGradle (`net.neoforged.moddev` 2.0.78), Gradle 8.10.2 через GitHub Actions
- Gradle wrapper у репозиторії ВІДСУТНІЙ: збірка йде через `gradle/actions/setup-gradle`
- Робота: GitHub у браузері (Android-планшет)

## Поточний стан (версія 0.1.1)
Збірка проходить, мод запускається, боби/рослина/блок/торгівля підтверджені користувачем у грі». Також додайте правило: «Для всіх моделей із прозорими текстурами обов'язково ставити render_type (cutout або translucent)».
Що далі (крок 2 першого етапу)
Боби на полях сіл.
Фермери самі садять і збирають боби. Для цього треба дозволити їм підбирати боби, інакше в них не буде що садити.

## Ще не зроблено (перший етап)
- Поява бобів на сільських полях (потрібно безпечно змінити процесори/шаблони полів)
- Щоб фермери садили боби: потрібні боби в їхньому інвентарі та дозвіл їм підбирати боби
  (`Villager.WANTED_ITEMS` — приватний список, ймовірно потрібен access transformer)
- Перевірка всього в грі

## Відомі помилки
Невідомі, бо збірку не запускали.

## Наступний крок
1. Запустити GitHub Actions «Build», надіслати лог/результат.
2. Виправити помилки компіляції, якщо є.
3. Перевірити в грі: посадка, ріст, врожай, рецепти, торгівля.
4. Потім: сільські поля і поведінка фермерів.

## Погоджені рішення
- Працюємо малими етапами; спершу бобова система.
- Ціни торгівлі (22→1, 1→4) обрав розробник, їх можна змінити.
